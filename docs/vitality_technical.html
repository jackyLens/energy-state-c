01

为什么要第二个状态量

能量 E 是慢变量：它回答"储备还剩多少"，由夜间恢复和日间消耗决定，一杯咖啡或一次午睡不会改变储备。但用户此刻的主观状态会变。精力层把这类短时的、会自己消退的偏离单独建模为 D，叠加在"能量 × 昼夜节律"的均衡线上：

V(t)  = clip( V*(t) + D(t), 0, 1 )
V*(t) = E(t) · [ 1 + ρ · c(t) ]                       ρ = 0.15，c(t) 复用能量层的节律形状
dD/dt = − D / τ_D(E) + Σ 事件脉冲 + 观测修正          τ_D = 0.75 h · (1 + 1.5 · (1 − E))
现象能量 E精力 V
下午咖啡，心率略升继续下降短暂上浮后约 1 h 内衰回
20 min 午睡略升立即回弹（示例 55.6 → 68.6）
1 h 会议，心率 +22 bpm 未动消耗加快，滞后过载，下压
比平时睡得好 / 差晨起 E 高 / 低醒来高于 / 低于均衡线（D_init）
没有观测时它退化为均衡线。D 的开环解是指数衰减，没有事件、没有残差时 |D| 单调不增（测试 test_open_loop），因此精力层不会"无中生有"。
02

级联结构：能量层不变，精力层只吃它的输出

D 没有并入能量层的状态向量。能量层已经在学个人基线，如果再加一维 D，"心率高是基线偏了还是 D 高"不可辨识。级联后能量层代码不变，只新增两列输出：观测更新前的 HR / HRV 残差 hr_resid / hrv_resid——能量层解释不了的部分，正是精力层要解释的部分。

精力层新增的量

  • 隐状态 D 与其方差 P（标量）
  • 个人常态 vitality_habit_t：夜间回充量、醒前 HRV、睡眠时长 / 深睡 / 碎片化、夜间血氧均值 / 下跌占比（EWMA，可持久化）
  • 本夜血氧 1% 分箱直方图（31 箱）
  • 50 桶的日间 V 分位直方图（按日历日指数衰减）

从能量层拿的量

  • E、e_sd（折进精力带宽）
  • sleep_prob（睡眠段判定）、load、activity（观测权重 / 事件）
  • hr_resid、hrv_resid（观测）
  • 昼夜节律形状 energy_circadian()（均衡线）
03

一步之内：预测、晨起、观测、裁剪、分位

流式接口 vitality_ctx_step 内部先走一次 energy_ctx_step，然后按六个阶段推进 D。批量接口 vitality_compute 是同一套代码逐点喂入，再加 15 min 的展示平滑（只平滑 vitality / score / 带，不改状态 v / d）；两者的 v / d 逐点一致到 1e-9（test_stream_equals_batch）。

预测

k = exp(−h / τ_D(E))        D ← k·D        P ← k²·P + q_d·h        q_d = 0.02 /h，P0 = 0.01（晨起先验标准差 0.1）

稳态 P ≈ q_d·τ_D/2 ≈ 0.0075，D 的先验标准差约 0.09；能量低时 τ_D 变长（最长 112 min），疲惫状态下任何波动都恢复得慢。

有界

−V* ≤ D ≤ d_cap · E          d_cap = 0.30：E = 0.4 时精力最多比均衡线高 0.12
04

观测：残差 z 化、倒 U 变换、标量卡尔曼

z_hr  = clip(hr_resid / 7, −6, 6)                 z_hrv = clip(hrv_resid / 0.40, −3, 3)
u(z)  = z · (1 − z / 2.8)    z ≥ 0                u(z) = 0.6 · z    z < 0         u ∈ [−2, 0.7]
y = H·D + ε      H = 3.0（心率）/ 2.0（HRV）      R = 1.0 / w_act（心率）/ 2.0 / w_act（HRV）
S = H²P + R      K = P·H / S      |y − H·D| / √S > 4 → 丢弃      D ← D + K·(y − H·D)      P ← (1 − K·H)·P

观测权重：为什么用活动量 A 而不是负荷 L

负荷 L 含心率项：心率一高 L 就高，用 L 排除观测会恰好把我们想测的"心率高但没动"排除掉。活动量 A 来自步数，是外生的，所以 A 是主判据：

w_act = clip( 1 − (A − 0.10) / (0.35 − 0.10), 0, 1 )
L > 0.60 且 A ≥ 0.10 → w_act = 0（在运动，不用）      L > 0.60 且 A < 0.10 → w_act × 0.5（保留但少信）

示例：09:30–10:15 心率 +10 bpm 未运动，D 由 +0.028 升至 +0.061；测试里 +22 bpm 持续 1 h 使 D 下降 > 0.01。

06

晨起初始化：四项都相对本人常态

x1 = clip( (ΔE − ΔE̅) / 0.30, ±0.5 )                          今晚能量回充量 vs 本人常态
x2 = clip( (HRV_wake − HRV̅_wake) / 0.44, ±0.5 )               醒前 1 h 的 HRV vs 本人夜间常态
x3 = clip( 0.5·q_时长 + 0.25·q_深睡 − 0.25·q_碎片, ±0.5 )       时长差 2 h / 深睡与碎片化差 10 个百分点记满分
x4 = clip( 0.5·q_血氧均值 − 0.5·q_瞬时下跌, ±0.5 )              v1.1：夜间血氧平稳度（§7）；没有血氧时为 0
D_init = 0.40 · clip( 0.4·x1 + 0.3·x2 + 0.3·x3 + 0.2·x4, ±0.5 )  |D_init| ≤ 0.2；没有常态的项记 0
规则说明
主睡眠判定sleep_prob ≥ 0.5 为睡眠段；连续 3 个清醒样本（15 min）结束；≥ 3 h 才算"一晚"，否则按小睡
常态学习前 3 晚累计平均（LEARNING），之后 EWMA λ = 0.2（约 5 晚记忆）；get/set_habit 持久化
续睡合并主睡眠结束后 2 h 内再次入睡 → 回滚上次常态更新，整夜重算（夜醒 20 min 不会拆成两晚，test_night_resume_merge）
不知道就不猜第一晚没有常态，D_init = 0

示例实测：第 4 天 07:10 起床 D_init = +0.033；第 5 天只睡 5 h，05:10 起床 D_init = -0.072。幅度没有到 −0.2 是因为 x1 项部分抵消：熬到 0 点才睡的人入睡时 E 更低，5 h 回充量并不比平时少多少；真实数据若证实，可改用"醒时 E 相对常态"或提高 w_sleep。

07

夜间血氧：只进晨起初始化，不进日间观测

戒指在指端做反射式 PPG，灌注好、夜间手不动，血氧的可用性明显高于腕戴设备。但"测得准"不等于"该用"——先看生理上它和精力有没有关系：

日间静息 SpO₂夜间 SpO₂
和精力的生理关系几乎没有。疲劳、压力、咖啡改变的是交感 / 副交感平衡与心率，不改变动脉血氧；健康人静息 SpO₂ 稳定在 96–99%，氧合曲线在这一段是平台，PaO₂ 变化几个 mmHg 都看不出来有。夜间通气不稳 → 短暂缺氧 → 化学感受器驱动的交感激活、心率突升、微觉醒。微觉醒常短于分期算法的分辨率，分期仍标"睡着"，但恢复质量已经打折。饮酒、鼻塞、仰睡、高海拔、感冒都先体现在这里
信噪比差：变化幅度（< 1%）小于传感器噪声（约 ±2%），手部活动伪迹大好：手不动、灌注稳定；只看相对本夜中位数的下跌，与绝对精度无关
与 HR / HRV 的关系—HR / HRV 看到的是交感激活这个结果；血氧看到的是通气不稳这个原因。两者相关但不冗余：心率突升可被分期 / 翻身解释掉，血氧下跌不会
结论不用用，作为晨起初始化第四项，权重 0.2

本夜统计（常数内存）

每个睡眠样本：low = min(spo2, spo2_min)  → 1% 分箱直方图 [70, 100]；mean 累加
整夜：median = 直方图中位数     dip = 占比( low ≤ median − 3 )     mean = 均值
覆盖：有效样本 ≥ 50% 睡眠样本 且 ≥ 1 h，否则本夜不用血氧（x4 = 0，不打 SPO2 标志，常态不更新）

相对本人常态

q_均值 = clip( (mean − mean̅) / 1.5, ±1 )     高于常态的正向收益减半（SpO₂ 有天花板，"比平时更高"信息量小）
q_下跌 = clip( (dip − dip̅) / 0.10, ±1 )       下跌占比比常态多 10 个百分点记满分
x4 = clip( 0.5·q_均值 − 0.5·q_下跌, ±0.5 )     x4 ≤ −0.25 时晨起点打 BREATH 标志（"昨夜呼吸不如平时平稳"）
规则说明
只看夜间日间样本的 spo2 字段被完全忽略；不做任何日间观测更新
只跟自己比均值与下跌占比都减去本人常态（前 3 个有血氧的夜累计平均，之后 EWMA λ = 0.2）；高原常住者的常态就是 92%，不会被当成"差"
不猜原因库只说"昨夜血氧比你平时不稳"，不区分饮酒 / 鼻塞 / 海拔 / 任何健康状况，也不设任何绝对阈值（如 90%）
可退化样本不传血氧（NAN / 0）、或 w_spo2 = 0 时，所有输出与 v1.0 逐位一致（test_spo2）；旧画像 vitality_habit_t（memset 0）可直接恢复
续睡合并夜醒后 2 h 内续睡，血氧直方图随分期统计一起保留，按整夜重算

示例实测：第 6 天睡够 8 h，但前一夜血氧均值 94.0%（平时 97%）、瞬时下跌占比 18%（平时 0%）→ x4 = −0.5，D_init = -0.040（同样的夜不带血氧时 D_init = 0.000），起床精力 82.3，均衡线 85.1。幅度上限是 0.04（0.40 × 0.2 × 0.5）：血氧被刻意放在"修正项"的位置，不会单独决定一天的起点。

为什么不把血氧做成日间观测通道？一旦加进去，卡尔曼更新会把传感器噪声当成状态变化：日间 ±2% 的抖动折算成 z 后与心率通道同量级，而它不携带任何精力信息，只会稀释真正的观测。用了不会更准，只会更吵。
08

两种 0–100 刻度，都只跟自己比

d_sd = sqrt( P + (V*/E)² · e_sd² )             lower / upper = 100 · clip( V ∓ 1.96 · d_sd )

能量层的不确定性按 V 对 E 的灵敏度折进精力带宽；冷启动时带宽大，随能量层基线建立而收窄。

接口

/* 流式：内部自带 energy_ctx_t */
vitality_ctx_t vc;
vitality_ctx_init(&vc, &ecfg, &vcfg);                 /* 配置可为 NULL */
vitality_ctx_set_habit(&vc, &saved_habit);            /* 可选：恢复个人常态 */
for (each 5-min sample) {
    energy_point_t ep; vitality_point_t vp;
    vitality_ctx_step(&vc, &sample, &ep, &vp);       /* ep.energy, vp.score, vp.quadrant, vp.flags */
}
vitality_ctx_event(&vc, VITALITY_EVENT_CAFFEINE, 0.0);  /* 用户标记，amplitude ≤ 0 用默认幅度 */
vitality_ctx_get_habit(&vc, &saved_habit);

/* 已有自己的 energy_ctx_t：拿到 energy_point_t 后 */
vitality_ctx_feed(&vc, &sample, &ep, &vp);

/* 批量（内含 energy_compute）*/
vitality_output_t out;
vitality_compute(samples, n, &ecfg, &vcfg, &out);     /* out.points / out.daily / out.energy / out.habit */
vitality_output_free(&out);

/* 命令行：能量列之后追加精力列 */
./build/energy_cli panel.csv --vitality --out out.csv
标志位含义
SLEEP / GAP / NO_OBS睡眠中 / 数据缺口 / 本点无可用观测（含运动中、能量基线未建立）
WAKE / LEARNING本点做了晨起初始化（d_init 字段有效）/ 前 3 晚学习期
EXERCISE / NAP / FATIGUE / USER本点注入了对应脉冲 / 拖拽
AROUSAL / STRESS轻度唤醒 / 过载（文案用）
PCT_READY分位刻度可用（≥ 3 个日间）
SPO2 / BREATH晨起点：本夜血氧覆盖充分、已参与初始化（spo2_night / spo2_dip 字段有效）/ 昨夜血氧平稳度明显低于本人常态

样本新增两个可选字段：spo2（窗口均值 %）与 spo2_min（窗口最低值 %），缺失填 NAN；能量层不读它们。CSV 对应列名 spo2, spo2_min。

非法配置：vitality_config_validate 逐项范围检查，vitality_compute 返回 ENERGY_EINVAL，流式上下文每步返回错误；时间倒退返回 ENERGY_EDOMAIN；NaN 输入按缺失处理（test_nan_fuzz）。

边界

没做的

  • 识别咖啡 / 冥想 / 压力事件的原因（只接受用户标记）
  • 跨用户的任何统计或排名
  • 离线参数拟合（与能量层一样放在 Python 端）
  • 医学用途

需要真实数据决定的

  • 短睡场景下 D_init 的 ΔE 项是否该换成"醒时 E 相对常态"
  • 清醒后首小时的残差是否要降权（能量层"心率随 E"假设的伴随现象）
  • 倒 U 零点 z_c 与各事件幅度
  • 分位窗口 28 天是否合适（轮班 / 出差）
  • 血氧项权重 0.2 与下跌判据 3 个百分点（取决于设备的 5 min 聚合方式；给得出 spo2_min 时更灵敏）
